# APS权重起步的Q/K训练设计

## 总览

状态：2026-10-11定稿。模块、训练入口及零更新工程核验已完成，见`docs/aps-warm-qk-engineering.md`；以下保留执行前协议；2026-10-12已完成唯一一次训练，结果见`docs/aps-warm-qk-fit.md`。

唯一问题：从已拟合的APS权重起步，恢复原M对361个棋盘token的自然注意力，仅更新Q／K及query归一化张量，能否改善原54题上的占用回答？主比较为同一次运行的训练前与固定终点，报告实际正确题数和CE差值，不设置“明显改善”档位。

文字提示仍包含坐标，但前向不再接收外部点位索引或单点mask。这是一个有限训练方案的实用性检查，不是“只差选点”的因果检验。自然注意力混合多个value后，冻结下游路径收到的输入也会改变；成功不证明注意力锁定所问点，失败不能定位原M失败原因或证明A1必需。

Claude指出，APS拟合的运行记录显示44个Q／K／query_norm张量始终未更新，保留seed42初始化；这里的起步优势来自其余APS参数的已拟合状态，不表示Q／K已经学会选点。

未训练的投影仍可随文字和棋盘改变输出，不能据此断言注意力均匀或与问题无关。

## 最小实现与工程边界

复用既有加载器、原M前向、评分与指标函数，只增加训练子集和状态转换所需的薄入口。小型检查针对转换、优化器成员、冻结与完整保存；不重复已有模型实验或另建核验框架。

1. 按APS合同加载完整101张量，再设置冻结标志。先恢复21道训练题，要求三标签原始logP最大差不超过预定`1e-5`，三类和全词表首选均一致。失败则停止，不放宽阈值重跑。
2. 关闭恢复阶段的路由观察hooks，清空专家、mask与点位引用。在原对象上将11个adapter和wrapper恢复为原M类，不重新包装基础模型。核对转换前后101个参数对象、名字、形状及字节不变，没有新增参数或随机初始化；自然前向使用原`grounding_eval`，不沿用APS路由封装。
3. 优化器恰含44个指定对象；57个其余adapter张量及base均冻结并排除。完整101名字与对象名单在冻结前保存，不能用按`requires_grad`筛选的接口代表完整检查点。
4. 保存完整101张量。计算架构恢复为原M，故文件使用`variant=m`，另记`training_recipe=aps_warm_qk`、源APS摘要、可训练名单、完成更新数及输入／源码摘要；不携带APS的`routing_contract`。无需新增架构类别。小型检查验证现有M加载入口兼容；实际结束时在同一模型上暂时恢复全部101的加载资格，调用现有加载器并核对字节，再恢复44／57标志。该检查不额外加载基础模型、不增加评分前向；不宣称独立新进程恢复已测。
5. 强制参数和损失有限、冻结57张量及base前后相同、优化器成员正确、输入与源码不变。记录44个逐张量的梯度与变化情况，但不要求每个张量字节必须变化：合法零梯度或浮点更新也可能产生未变化张量。

## 预算与结束条件

在更新0的54题评估后，以该次实际耗时计算收尾预留`max(300秒, 2×初始54题耗时+60秒)`。这是保守工程余量，不是耗时保证。每次启动下一更新前，必须仍留有该预留及已观察最慢一步的时间；计时从外层进程开始。预算不足或非有限值时停止更新，保存实际阶段和原因，不追加第二次尝试。

完整有效终点须同时满足：恰好1,000次返回更新、既定4,000槽全部消费、初始与最终各54题完整、恢复／冻结／来源／有限性及保存加载检查通过、真实OS正常退出、外部总时长在1,800秒内。原生计算或文件收尾可能超出软预算；如发生，必须报告实际时长并撤销“预算内完整”结论。

未达1,000步而终评覆盖54题，可保留该更新数下的描述结果，不作为预定终点；缺失覆盖或核验项分别记录。非有限值、恢复失败或源不一致不归类为训练方案的有效失败。训练主循环本体尚未实际执行；若首次运行出现`status=error`等程序异常，属于工程失败，不是该训练方案的有效负结果。修复后需另行限定新运行范围，不自动补跑。无自动补跑、调参、延长、另加训练臂或付费计算。

## 结果怎样解释

主表并列更新0与固定终点的正确数／54、三类混淆矩阵、各盘／18、各行棋方／27、三类CE和全词表CE；每步训练CE仅作过程描述。旧恒空18/54、坐标×行棋方先验19/54、旧自然模型20/54及辅助54/54作为不同权重／监督的背景参考，不能当作匹配训练臂或净路由效应。只有3盘相关棋局，不把54题当作54个独立样本。

在同一评分函数与输入、其余参数冻结且终点有效的条件下，超出数值差异范围的前后变化可归于这44个张量的联合更新；这一级归因不识别内部选点机制。固定的是`LN_e(f+p)`输入表示，投影`W_K`仍可学习；若结果不足，无法区分固定表示、下游对混合输入的适应、有限优化或预算等因素。位置编码大小本身也不是可寻址性的判据。

改善只支持这份已查看、提示重叠列表上的训练方案效果；高分不识别点位注意力机制，低分不排除其他配置、预算或架构。若更新0已经高分，直接如实报告，不改变实验分支。任何结果都不自动触发下一次运行。

本阶段选择这一方案作为唯一后继设计；不追加特征替换测量。现有同提示、不同棋盘的正确回答已支持专家输入影响答案，继续细分该依赖并非当前推进自然注意力回答的必要前置条件。预计约20分钟来自其他配置单步耗时的粗略外推，尚未实测；1,800秒是所选资源上限，不是已证明的充分训练时间。

# M-APS 单次拟合入口

## 总览

训练入口与外部进程记录入口已实现，新增28项入口检查、25项模拟生命周期检查和2项tiny优化器检查通过。2026-10-11已完成唯一一次真实M-APS事实拟合：180次更新、720个槽位、固定终点21/21，OS退出码0、外部209.861817秒；有效终点为`full_fit`。详见[单次拟合结果](assisted-point-fit.md)。本阶段停止，不自动追加实验。

M-APS按问题中已给的坐标，从棋盘特征中选择一个点；答案标签只参与损失与评分。它用来检验辅助选点后整个下游路径的有限拟合能力，不能证明自然坐标寻址、泛化或原M失败的唯一原因。

## 固定配置

- 使用原21个事实题、5份缓存特征；保持原提示、标签、seed42初始化和720个采样槽位。
- batch4，最多180次AdamW更新；lr0.001，betas(0.9,0.999)，eps1e-8，weight decay0，无warmup或梯度裁剪。
- 冻结基础模型与专家特征，CPU4、FP32、math SDPA；训练使用完整词表的因果值token交叉熵，三类归一化交叉熵另报。
- 评估使用batch1。初始和终点评估请求全部21题；60、120更新的中间评估可为预算收尾而跳过，不能用中途峰值替换固定终点。
- 300秒为包含导入、校验、加载、训练、评估、哈希、保存及报告的软预算。原生计算可能延迟信号；外部入口记录真实退出、信号及子进程墙钟，超预算不给有效终点类别。

## 必要运行合同

训练前核对事实清单、源文件、初始化、采样、前缀与全部21题原始初始分数。每次实际前向核对11层单点布尔mask、坐标与批次顺序，并检查绑定清理。优化器只能包含原101个桥接张量；44个Q/K/query_norm张量每次反向须零梯度，最终字节保持相同。

有效终点要求180次优化器更新实际返回、最终21个固定题ID各出现一次、分数与参数有限、各合同通过、冻结基础模型末次哈希已测且相同，并且拟合权重已保存并通过实际加载器元数据与字节回读。当前模型上的字节回读不等价于另建模型后的恢复logits测量。

外部进程入口再检查真实OS退出、信号、预算与报告字段。不完整、非有限、复现不符、保存不全或超时的结果只保留实际覆盖与描述性指标。它们不算完整拟合失败。

有效运行与拟合成功分别报告：正确数越过16/21、三类CE低于0.866917941以及全21题gold margin通过各自容差，不能互相替代。数值容差是工程guard，不是统计显著性。
